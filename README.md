# Mentor Literario

Una skill para Claude Cowork diseñada para análisis, edición y mejora de textos literarios con foco en preservación de voz autoral.

## Descripción

**Mentor Literario** es un skill especializado para escritores que buscan mejorar sus textos sin perder su identidad creativa. Funciona como mentor crítico, editor de precisión y entrenador técnico simultáneamente.

### Principios Fundamentales

- **Preservación de voz**: Afilar, no reemplazar. Ordenar, no domesticar.
- **Alta fidelidad**: Análisis técnico riguroso sin intervención artificial.
- **Fidelidad al autor**: La mejor versión posible del texto del autor, no una versión "genérica de buena literatura".
- **Honestidad crítica**: Cuando algo no funciona, se dice claramente. Cuando está bien, se respeta.

## Uso

### Instalación

- **Claude Code:** cloná este repositorio en `~/.claude/skills/mentor-literario/`. La skill es el archivo `SKILL.md`.
- **Claude (web, escritorio o Cowork):** comprimí en un `.zip` una carpeta `mentor-literario` que tenga adentro el `SKILL.md`, y subila en la sección de Skills de la configuración.

Está escrita para mis textos: la descripción del encabezado me nombra. Para usarla con los tuyos, cambiá ese nombre.

### En Chat

Simplemente comparte tu texto y pide:

```
"Analiza este texto" (para análisis completo)
"Está en crudo" (para textos en fase embrionaria)
"Dame inspiración para..." (para estímulo creativo)
"Corpus analysis" (para analizar múltiples textos juntos)
```

## Qué Analiza

- **Núcleo temático**: El centro gravitacional real del texto
- **Arquitectura**: Estructura, progresión, cierre
- **Imágenes dominantes**: Fortalezas, redundancias, coherencia simbólica
- **Campos semánticos**: Universos de palabras y coherencia
- **Tensiones internas**: Oposiciones que generan sentido
- **Ritmo y musicalidad**: Cadencia, pausas, respiración
- **Sintaxis**: Fluidez, construcción de frases
- **Densidad**: Economía expresiva
- **Subtexto**: Lo que se comunica sin decir
- **Voz**: Identidad recurrente del autor

## Características

### Textos Crudos
Detecta potencial en material embrionario sin forzar pulido prematuro.

### Inspiración
Proporciona campos semánticos, imágenes, asociaciones y estructuras alternativas en lugar de escribir por ti.

### Análisis de Corpus
Detecta recurrencias, evolución cronológica y patrones de crecimiento en conjuntos de textos.

### Componente Didáctico
Cada análisis incluye concepto técnico + ejercicio de tensión para entrenar capacidades específicas.

### Preservación Cultural
Respeta y mantiene regionalismos, marcas culturales argentinas y giros sintácticos característicos.

## Géneros Soportados

- Poesía
- Prosa poética
- Narrativa breve
- Teatro
- Reflexión existencial

## No Es

- Un corrector automático
- Un generador de textos
- Una validación emocional
- Un instructor de "cómo escribir"

## Cómo se hizo

La armé trabajando con Claude: el criterio de lectura y la lista de lo que no se toca son míos; Claude los ordenó como instrucciones que otro Claude puede seguir.
