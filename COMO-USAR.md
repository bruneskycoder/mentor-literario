# Cómo Usar Mentor Literario

## Instalación Rápida

### GitHub
1. Clonás el repo: `git clone https://github.com/tuusuario/mentor-literario.git`
2. Copias `skill/mentor-literario.md` a tu carpeta de skills de Claude/Cowork
3. Listo — ya funciona

### Sin Clonar
Simplemente copias el contenido de `skill/mentor-literario.md` y lo pegas en tu chat como un skill personalizado.

## Casos de Uso

### 1. Analizar un Texto Terminado
```
Analiza este poema y decime qué está funcionando y qué no.

[Tu texto aquí]
```

Recibirás: análisis estructurado + versión pulida + concepto técnico + ejercicio.

### 2. Trabajar Texto en Crudo
```
Está en crudo. Lo escribí en 10 minutos sin filtro.

[Tu texto aquí]
```

Recibirás: identificación de potencial + separación de material fuerte/débil + arquitecturas posibles.

### 3. Pedir Inspiración
```
Dame inspiración para un texto sobre la imposibilidad de elegir, desde lo existencial.
```

Recibirás: campos semánticos + imágenes + tensiones + recursos técnicos + direcciones narrativas. NO un texto escrito por mí.

### 4. Analizar un Corpus
```
Aquí van 10 poemas que escribí a lo largo de 2 años. Dame un análisis del corpus.

[Tus textos aquí]
```

Recibirás: recurrencias + evolución cronológica + patrones de crecimiento + textos con mayor potencial.

## Qué Esperar

- **Honestidad**: Si algo no funciona, se dice. Sin validaciones emocionales falsas.
- **Respeto por tu voz**: Nunca te van a "mejorar" en un estilo que no es el tuyo.
- **Componente didáctico**: Cada análisis incluye un ejercicio para entrenar una capacidad específica.
- **Material de reserva**: Cuando hay ideas valiosas para otro texto, se señala.

## Qué NO Es

- Un corrector automático (aunque también corrige)
- Un generador de textos (aunque también inspira)
- Un validador emocional (aunque lee profundo)
- Un reemplazo del editor real (aunque funciona como uno)

## Preguntas Frecuentes

**¿Puedo usarlo para cualquier texto?**
Mejor para textos propios, literarios o reflexivos. No está diseñado para análisis de textos ajenos ni para escritura técnica/académica no creativa.

**¿Qué pasa si le doy un poema comercial o publicitario?**
Va a analizarlo igual, pero la skill está pensada para literatura, así que el resultado puede no ser óptimo.

**¿Puede reescribir mi texto completamente?**
No. La premisa es preservar tu voz. Propone cambios mínimos, nunca reescrituras totales (a menos que sea absolutamente necesario).

**¿Y si no estoy de acuerdo con el análisis?**
Es data que provee, no verdad absoluta. Usala como perspectiva externa. Tu intuición también cuenta.

## Créditos
